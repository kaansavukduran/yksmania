# Teknoloji ve platformlar

React ve TypeScript uygulaması [Vite](../vite.config.ts) ile derlenir. Web, Windows, Linux ve Android hedefleri çevrimdışı kullanım üzerine kurulur. Electron masaüstünü, Capacitor Android paketini taşır. IndexedDB yerel kaydı, servis çalışanı web çevrimdışı açılışını destekler.

Komutlar [package.json](../package.json) içindedir. npm ci bağımlılıkları kurar. npm run dev geliştirmeyi, npm run build üretim derlemesini, npm run preview üretilen uygulamayı açar. Test ve yayın adımları [işletim belgesindedir](OPS.md).
